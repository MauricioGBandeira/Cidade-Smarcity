Spring Boot - Framework utilizado para construir a API.

Insomnia - Ferramenta para testes de API.
Banco de Dados (local) - Implementado via Docker.

## Sobre

*#Cidade-Smarcity** é uma aplicação desenvolvida em Java que utiliza uma API para cadastramento e agendamento]. Ele usa Maven para gerenciar dependências e JSON como formato de troca de dados. Este projeto permite que os usuários Façam um agendamento para que caminhoes retirem materiais reciclaveis.
